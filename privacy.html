Hermes personal: privacy policy

Last updated 17 October 2026

Hermes is a personal tool. I am its only user, and nobody else can sign in to it.

What it reads

After I sign in with Google, Hermes reads data from my own Google account and no other:

  • Gmail: the sender, recipients, subject and date of each message, plus Gmail's short preview text. It doesn't download message bodies or attachments.
  • Google Calendar: event titles and times.

If I grant the extra permissions, it can also create Gmail drafts and calendar events, each one only after I approve it. It never sends, deletes or relabels email.

Where the data stays

Everything is processed and stored on my own server, and the sign-in tokens sit in a private file there. The data isn't sold or shared with anyone, and it isn't used for advertising or to train AI models.

Google API data

Hermes' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

I can remove Hermes' access at any time at myaccount.google.com/permissions.
